# 🏋️ Workout Bot — Состояние проекта (Бортовой журнал)

## 1. Стек и архитектура
- **Язык:** Python 3.12
- **Фреймворк:** aiogram 3.x
- **БД:** PostgreSQL + SQLAlchemy 2.0 (asyncpg)
- **Архитектура:** Слой хэндлеров (aiogram), слой моделей (SQLAlchemy), слой запросов (`app/db/queries.py`).
- **Запуск:** Docker Compose (БД на порту 5433, чтобы не конфликтовать с локальным Postgres).
- **Виртуальное окружение:** `.venv`

## 2. Ключевые сущности (БД)
- `User` — пользователи (привязка по `tg_id`).
- `WorkoutType` — шаблоны тренировок (например, "Ноги и плечи"). Имеет флаг `is_archived` (мягкое удаление).
- `Exercise` — упражнения в шаблоне. Типы (`kind`): `strength` (подходы/повторы/вес), `warmup`/`cardio` (длительность). Имеет флаг `is_optional` (опциональное) и `is_archived`.
- `WorkoutSession` — факт выполнения тренировки (начало/конец).
- `SessionSet` — фактически выполненные подходы (снимок reps/weight на момент выполнения).

## 3. Архитектурные решения и паттерны
- **Даты:** В БД храним UTC, на экран выводим в МСК (функции в `app/utils.py`: `to_msk`, `fmt_msk_date`, `fmt_msk_time`, `fmt_msk_datetime`).
- **Удаление:** Если у сущности (тренировка/упражнение) есть история (`SessionSet`), она не удаляется физически, а архивируется (`is_archived = True`). Это защищает историю от FK-ошибок и потери данных.
- **Отмена (FSM):** Любой диалог ввода кладет в `state` ключ `return_to` (например, `"ex_card"`, `"tr_list"`). Обработчик `/cancel` и кнопка `❌ Отмена` (`fsm_cancel`) читают этот ключ и возвращают пользователя на нужный экран.
- **Фильтрация архивных:** В `_load_workout` и `_load_workout_with_exercises` используем `selectinload(WorkoutType.exercises.and_(Exercise.is_archived.is_(False)))`. **ВАЖНО:** Нельзя фильтровать через `wt.exercises = [...]`, так как `cascade="all, delete-orphan"` удалит архивные упражнения из БД.
- **Опциональные упражнения:** Не портят статистику. В прогрессе считаются как `total` только если начаты (или если они обязательные).
- **Редактирование кардио/силовых:** Всегда создается `SessionSet`. При повторном входе в кардио оно **редактируется** (перезаписывается `duration_seconds`), а не создает новый подход.
- **Режим "Продолжить":** Если есть активная сессия (`finished_at IS NULL`), в карточке тренировки кнопка меняется на "▶️ Продолжить тренировку".

## 4. Текущий функционал (Готово)
- Регистрация, создание/удаление/архивация тренировок.
- Создание/редактирование/архивация упражнений (силовые и кардио).
- Процесс тренировки: старт, экран прогресса, ввод фактических данных, экран итогов упражнения (сводка подходов/времени).
- Добавление/удаление упражнений "на ходу" во время тренировки.
- Умный `/cancel` с возвратом на нужный экран.
- Валидация ввода (вес, время в минутах с поддержкой дробей).
