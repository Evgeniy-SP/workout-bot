# 🏋️ Telegram-бот для учета тренировок (Workout Bot)

![Coverage](./coverage.svg)

Этот бот создан для удобного ведения дневника тренировок прямо в Telegram. 
Он позволяет планировать программы, записывать фактические результаты, отслеживать отдых и вести историю.

## 🚀 Основные возможности (C1)
- **Справочник:** Создание тренировок и упражнений (силовых и кардио).
- **Умные подсказки:** Бот автоматически подтягивает веса и повторения из прошлой тренировки, показывая дату.
- **Текстовый вес:** Возможность писать «Своё тело», «Резинка», «10 блоков» вместо чисел.
- **Опциональные упражнения:** Разминки и заминки, которые не портят статистику, если их пропустить.
- **Таймеры отдыха:** Встроенные таймеры (60с, 90с, 3 мин, своё время) с фоновыми уведомлениями и автоудалением.
- **Цифровые клавиатуры:** Ввод весов и повторений через удобные inline-кнопки.
- **Заметки:** Возможность оставить комментарий к упражнению (текущий и прошлый) и ко всей тренировке.
- **Умная ротация:** Главное меню сортирует тренировки по дате последнего выполнения.

## 🧠 Ключевая логика работы (Как это устроено под капотом)

### 1. План vs Факт
- **План (Шаблон)** — настраивается в меню «Упражнения». Хранит целевые подходы, повторения и вес.
- **Факт (Активная тренировка)** — то, что ты делаешь в зале. Вводя фактические данные, ты не меняешь шаблон, но создаешь историю.

### 2. Приоритет истории (Вес и Повторения) и Плана (Подходы)
- **Вес и повторения** бот подтягивает из *истории* (из последнего выполненного подхода в прошлой тренировке). Бот пишет «В прошлый раз (дата)» и предлагает кнопку для автозаполнения.
- **Количество подходов** всегда берется из *шаблона*. Если сделал больше, можно добавить через кнопку «Добавить подход».

### 3. Опциональные упражнения (Разминки/Заминки)
- Скрываются из основного списка в «Папку опциональных».
- Если не сделал — не портят прогресс (не идут в знаменатель).
- Если сделал — подтягиваются в основной список на свое место.

### 4. Умная ротация
- В главном меню тренировки сортируются по дате: ту, что не делал дольше всех, бот поднимает наверх.
- Тренировки «вне ротации» (например, тестовые) всегда висят внизу.

### 5. Безопасность и Архив
- Удалить навсегда можно только то, что не имеет истории (или после двойного подтверждения).
- Архивация позволяет убрать упражнение/тренировку из глаз, но сохранить все подходы и заметки.

## 📦 Технический стек
- **Язык:** Python 3.12
- **Библиотеки:** aiogram 3.x, SQLAlchemy 2.0, asyncpg, docker
- **База данных:** PostgreSQL (в Docker-контейнере на порту 5433).
- **Резервное копирование:** Автоматические дампы `.sql` через скрипт.
